# 郑软AI助手 项目文件说明文档

> 郑软AI助手 - LLM powered virtual character
> 版本: 0.9.0
> 许可证: MIT

***

## 项目概述

Project AIRI 是一个基于 LLM（大型语言模型）驱动的虚拟角色项目，采用 Monorepo 结构，使用 pnpm workspaces 管理多个应用和包。

### 技术栈

- **运行时**: Node.js, Electron
- **框架**: Vue 3, Hono, Vite
- **构建工具**: Turbo, tsdown, electron-vite
- **数据库**: PostgreSQL (Drizzle ORM), Redis, DuckDB WASM
- **认证**: Better Auth, OIDC
- **可观测性**: OpenTelemetry
- **样式**: UnoCSS, Reka UI, Tailwind Wind3

***

## 项目架构总结

### Monorepo 结构

```
098765/
├── apps/                  # 应用程序
│   ├── server/           # 后端 API 服务器 (Hono)
│   ├── stage-web/        # Web 端应用
│   ├── stage-pocket/     # 移动端应用 (Capacitor)
│   ├── stage-tamagotchi/ # 桌面端应用 (Electron)
│   ├── ui-server-auth/   # 认证 UI
│   └── component-calling/ # 组件调用演示
├── packages/             # 共享包
│   ├── audio/            # 音频处理
│   ├── ccc/              # 角色卡片导出
│   ├── core-agent/       # Agent 运行时
│   ├── core-character/    # 角色管道
│   ├── i18n/             # 国际化
│   ├── pipelines-audio/   # 音频管道
│   ├── plugin-sdk/       # 插件 SDK
│   ├── server-runtime/   # 服务端运行时
│   ├── server-schema/    # 数据库 Schema
│   ├── server-sdk/       # 客户端 SDK
│   ├── stage-ui/        # UI 组件库
│   ├── stage-ui-three/   # 3D 组件
│   ├── ui/              # 基础 UI
│   └── ...              # 更多包
└── engines/             # 游戏引擎集成
    └── stage-tamagotchi-godot/ # Godot
```

### 技术特点

1. **多平台支持**: Web、移动端 (iOS/Android)、桌面端 (Electron)
2. **实时通信**: WebSocket 聊天、AI 语音交互
3. **AI 集成**: LLM 模型网关、AI 角色管理
4. **支付系统**: Stripe 集成、Flux 计费系统
5. **可观测性**: OpenTelemetry 日志、追踪、指标
6. **认证系统**: Better Auth + OIDC 多提供商认证
7. **插件系统**: 可扩展的插件架构
